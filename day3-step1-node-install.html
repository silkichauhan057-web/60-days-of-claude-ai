DAY 3 · FOUNDATION SETUP

Step 1: Install Node.js

What it is (plain English): Node.js is a program that lets your computer run JavaScript code outside of a web browser. Think of it as the "engine" that powers your development tools — you won't write raw Node code much, but nearly every tool we use (Expo, npm, React Native) depends on it being installed.
Why we need it for CircleUp: Expo CLI (which builds our mobile app), npm (Node's package manager — used to install libraries like React Navigation and Firebase), and most of our toolchain requires Node.js to run at all.

Instructions (Windows)

1. Check if you already have it installed
  1. Press Windows key, type cmd, press Enter to open Command Prompt.
  2. Type this and press Enter: 
    node -v
  3. If you see a version number like v20.11.0 — Node is already installed. Skip to the confirmation step at the bottom.
  4. If you see 'node' is not recognized... — it's not installed. Continue below.
2. Download Node.js
  • Go to: https://nodejs.org
  • Download the LTS version (left button, labeled "Recommended for Most Users"). LTS = Long Term Support — the stable, well-tested version, not the bleeding-edge one.
3. Run the installer
  1. Open the downloaded .msi file.
  2. Click "Next" through the wizard, accepting the license agreement.
  3. Leave all default options checked — including "Add to PATH". This is important: it lets you run node from any terminal window.
  4. Click "Install," then "Finish."
4. Verify installation
  1. Close and reopen Command Prompt (required — it won't recognize the new install until restarted).
  2. Run: 
    node -v
npm -v
  3. You should see two version numbers, e.g. v20.11.0 and 10.2.4.
