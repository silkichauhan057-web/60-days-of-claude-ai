Welcome to day48

This is a personal AI playbook built around how you actually work: debugging, code review, docs, architecture and learning — with Claude. Instead of generic prompts, it gives you reusable systems you can fill in and reuse on any project.

  • Workflows — editable prompt templates with variables, examples and best practices for your recurring tasks.
  • Prompt Builder — assemble a prompt from labelled blocks (role, constraints, format…) with a live preview, so nothing generic sneaks in unnoticed.
  • Loop Builder — turn any prompt into a self-checking, self-stopping iteration loop.

Everything you save stays in this browser's local storage. Export a backup anytime from the sidebar.

What is this?

day48 is a personal library of reusable AI prompt systems for a software engineer's daily work with Claude — debugging, code review, documentation, architecture planning and learning new tech.

  • Dashboard — an overview of your library and quick links into the other sections.
  • Workflows — a searchable library of prompt templates. Each has fill-in variables, a worked example, and best practices. Copy the filled-in result straight into Claude.
  • Prompt Builder — build a prompt piece by piece from labelled blocks (role, objective, context, constraints, reasoning strategy, output format, tone, examples, quality checks) instead of one vague paragraph.
  • Loop Builder — wrap any prompt in an iterate-evaluate-stop structure: define a goal, how success is judged, how to improve between passes, when to stop, and hard safety limits.

Data is stored only in this browser (local storage) — nothing is sent anywhere. Use Export/Import in the sidebar to back up or move your library.
